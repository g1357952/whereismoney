Supabase 一次性設定

連線前需要完成 4 件事

  1. 1

    建立 Supabase 專案，開啟隨附的 supabase-setup.sql，貼到 SQL Editor 執行。

  2. 2

    到 Authentication → Providers 啟用 Google，並依 Supabase 顯示的 Callback URL 設定 Google OAuth。

  3. 3

    到 Authentication → URL Configuration，把目前 EZPage 網址加入 Redirect URLs。

  4. 4

    把 Project URL 與 Publishable Key 貼回本頁設定，儲存後使用 Google 登入。
